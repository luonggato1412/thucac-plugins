# Từ điển cho Thư Các

App Thư Các (từ 0.6.18) tự tải hai file này một lần khi mở lần đầu, để APK nhỏ hơn.

- `VietPhrase.txt.xz`, `Names.txt.xz`: nén xz, giải nén ra UTF-8 dạng `中文=nghĩa`.
- Nguồn: github.com/thiendiepdt/quick-translator-engine (QT2025).

- `ChinesePhienAmWords.txt.xz`, `Pronouns.txt.xz`, `LuatNhan.txt.xz`: Phiên âm Hán Việt, Đại từ, Luật nhân, cùng định dạng, lấy từ bộ TuDien-ThuCac (QT2025). Nút "Tải/cập nhật từ điển mặc định" trong app tải cả 5 file.
